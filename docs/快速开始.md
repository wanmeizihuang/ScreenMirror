# ScreenMirror 快速开始

> 当前版本：Android → Windows 局域网投屏 + 反向控制（LibVLCSharp 解码方案）。
> 与旧文档不同：**手机主动连电脑**，不是电脑连手机；**无音频、无加密、无 WiFi 直连**。

## 一、环境准备

### Windows 端（接收端）
1. 安装 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
2. 构建并运行：
   ```
   dotnet restore server/src/ScreenMirror.Server.csproj
   dotnet build server/src/ScreenMirror.Server.csproj -c Release
   dotnet run --project server/src/ScreenMirror.Server.csproj
   ```
   构建产物也可通过 `package_windows.bat` 打包为独立发行包。

### Android 端（发送端）
1. 用 Android Studio 打开 `client/android` 目录
2. 同步 Gradle，运行/打包到设备（或直接使用已生成的 `release/ScreenMirror.apk`）

## 二、使用步骤（投屏）

1. 确保**手机与电脑在同一局域网 WiFi**。
2. 电脑端运行 ScreenMirror → 主窗口显示「等待设备连接…」，并自动开始设备扫描。
3. 手机端打开 ScreenMirror App → 点击「扫描设备」→ 电脑会出现在设备列表中（也可手动输入电脑 IP）。
4. 点击设备 → 系统弹出**录屏授权** → 允许。
5. 授权后手机主动 TCP 连电脑，电脑自动打开投屏窗口，画面开始显示。
6. 点投屏窗口右上角「断开」可结束。

## 三、开启反向控制（用电脑控制手机）

反向控制默认需要手机端授权，步骤如下：

1. 在手机「设置 → 无障碍 → 已安装的服务」中，找到并开启 **ScreenMirror**。
2. 投屏过程中，将**鼠标移动到电脑的投屏窗口上**，即可：
   - 鼠标移动 / 左键点击 / 右键 → 对应手机触摸；
   - 键盘输入 → 对应手机按键。
3. 坐标会自动按投屏窗口比例归一化（含横竖屏旋转修正）。

> 说明：反向控制仅在鼠标位于投屏窗口上时才转发，不会误控电脑其他界面。未开启无障碍服务时，指令会被手机端忽略。

## 四、后台投屏稳定性（鸿蒙等激进后台管理机型）

部分机型（如鸿蒙 6.0）进入后台后会冻结 App 的编码器线程，导致画面卡死。已采取以下措施：

- 屏幕采集服务持有 `PARTIAL_WAKE_LOCK` 并设为高优先级前台通知；
- 仍建议手动操作以提升稳定性：
  1. 手机「设置 → 应用 → ScreenMirror → 电池」→ 关闭「省电/受限后台」或设为「允许后台活动」；
  2. 投屏时尽量保持 App 在前台，或减少切后台的时长。

## 五、常见问题

- **电脑扫不到手机**：确认同一 WiFi；可改用 App 内「手动输入 PC IP」直接添加。
- **画面卡住/信号丢失**：网络抖动或手机编码器被冻结；App 回到前台通常自动恢复，PC 端 6 秒无数据会自动重置解码器。
- **反向控制没反应**：检查手机端无障碍服务是否已开启；鼠标是否在投屏窗口上。
- **连接失败**：确认电脑防火墙未拦截 35354 / 35357 端口。

## 六、项目目录（节选）

```
Wifi投屏/
├── protocol/          # 通信协议（手写二进制，非 Protobuf）
│   ├── csharp/        #  C# 协议库
│   ├── kotlin/        #  Kotlin 协议库
│   └── protocol-spec.md
├── server/            # Windows 接收端 (.NET 8 WPF + LibVLCSharp)
│   └── src/
│       ├── modules/   #  vlc-decoder / screen-mirror / reverse-control
│       ├── plugins/   #  插件管理器
│       └── ui/        #  MainWindow + MirrorWindow
├── client/android/    # Android 发送端 (Kotlin + Compose)
│   └── app/src/main/java/com/screenmirror/
│       ├── core/      #  ScreenCaptureService / DeviceDiscoveryService
│       ├── modules/   #  ReverseControlService
│       └── ui/        #  MainActivity
└── docs/              # 设计文档
```
